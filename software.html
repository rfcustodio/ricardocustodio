Data and Reproducibility

Datasets, experimental results, benchmarks, and reproducibility packages will be incorporated as they are curated. When appropriate, preserved research objects will be linked to persistent repositories and identifiers.

Preservation Model

The long-term preservation strategy separates three layers:

  1. Development — source code and active collaboration environments;
  2. Publication — stable releases associated with papers, projects, and academic outputs;
  3. Preservation — durable research objects with persistent metadata and, where appropriate, archival repositories and DOIs.

This structure is intended to preserve relationships such as:

project → software → release → dataset → publication → student → talk
